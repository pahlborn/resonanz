# Resonanz

Du regst an. Das Feld entscheidet, ob und wie stark es antwortet. Was in
Resonanz war, hinterlässt Farbe.

Kein Generate-Knopf, keine Regler, keine KI, keine Cloud, kein Konto. Die Hand
ist die Schnittstelle. Alles läuft offline im Browser.

**[Resonanz öffnen](https://pahlborn.github.io/resonanz/)**

Auf dem iPad in Safari öffnen → Teilen → „Zum Home-Bildschirm". Danach läuft
es im Vollbild und ohne Netz.

## Wie es sich bedient

Kreisen mit dem Finger erzeugt einen Wirbel. Ein gerader Zug legt einen Strang.
Wer mitten in der Drehung loslässt, schickt den Wirbel auf Reise. Mehr muss man
nicht wissen; alles andere findet die Hand.

Unten rechts ein Punkt. Ein Tipp öffnet drei Wege:

* **Sichern** — legt das Bild in die Galerie, mit dem Namen der Fassung
* **Galerie** — was du gesichert hast, nur auf diesem Gerät
* **Regal** — alles, was gebaut wurde

## Das Regal

**[Die Wirkungen](https://pahlborn.github.io/resonanz/regal.html)** — jede für
sich zu erleben, mit ihrem Namen: Wirbel · Strang · Wurf · Korn · Funken · Stoß ·
Sog · Zwei Stimmen · Schleife · Tempo · Strömung · Verblassen in drei Stärken.

**Die Fassungen** — A bis R, in denen mehrere Wirkungen zusammenkommen. Jede
bleibt für immer erreichbar. R ist die, die beim Start kommt.
